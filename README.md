# TryTravel

Laravel 13 и PHP 8.3+. Публичные страницы и формы используют вёрстку первого курсового. Регистрация, вход и выход работают через базу данных. Страницы личного кабинета доступны после входа.

## Локальный запуск

1. Запустите MySQL 8.0.16+ или MariaDB 10.11. Импортируйте `database/TryTravel.sql` пользователем базы данных с правом создания схемы.
2. Скопируйте `.env.example` в `.env`. Заполните `DB_USERNAME` и `DB_PASSWORD` реквизитами локальной учётной записи, у которой есть доступ на чтение и запись в БД `trytravel`.
3. Выполните `composer install --no-dev` и `php artisan key:generate`.
4. Выполните `php artisan serve --host=127.0.0.1 --port=8000` и откройте [TryTravel](http://127.0.0.1:8000/). Сборка фронтенда не требуется.

Схема создаётся SQL-файлом. Значение `bookings.checking` равно 1 для подтверждённой брони или 0 при отсутствии подтверждения. Для регистрации назначается роль с `role_id = 1`. Отдельные функции восстановления пароля, подбора туров из базы, обработки заявок, документов и избранного предстоит подключить.
